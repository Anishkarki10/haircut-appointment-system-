💈 Haircut Appointment Booking System

A cross-platform haircut appointment booking application developed using Flutter by Team Codex as a group project.

The application aims to simplify the process of booking haircut appointments by connecting customers with barbers and salon owners through a convenient mobile platform.

📱 Supported Platforms

* 🤖 Android
* 🍎 iOS

🚀 Features

Customer Features

* User registration and login
* Browse available salons and barbers
* View salon services and pricing
* Book haircut appointments
* Select preferred dates and times
* View and manage appointments
* Cancel appointments

Salon Owner Features

* Salon owner registration and login
* Manage salon profiles
* Add and update services
* Manage appointment bookings
* Set available appointment slots
* View customer appointments

Note: Features listed above are planned functionalities and may change during development.

⚙️ Installation & Setup

Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Xcode (required for iOS development on macOS)
* Git

1. Clone the Repository

git clone https://github.com/YOUR_USERNAME/HaircutAppointmentCodex.git

2. Navigate to the Project

cd HaircutAppointmentCodex

3. Install Dependencies

flutter pub get

4. Run the Application

For Android:

flutter run

For iOS (macOS required):

flutter run -d ios

To check available devices:

flutter devices
